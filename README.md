# stampyaml

Stamp encode/decode helpers for yaml payloads in pipelines.

**Site:** https://theworker02.github.io/stampyaml/

## Install / run

```bash
git clone https://github.com/theworker02/stampyaml.git
cd stampyaml
node src/cli.js
node --test
```
